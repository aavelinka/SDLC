## Описание

Проект предназначен для разработки приложения «Калькулятор жизни» на языке C++.

Программа должна рассчитывать:

- количество часов, проведённых за компьютером;
- количество суток за компьютером;
- пробег курсора;
- количество кликов мышью;
- количество нажатий клавиш.

Графический интерфейс реализуется средствами Win32 API.
Сборка выполняется с помощью CMake.

## Структура проекта

- src — исходные файлы;
- include — заголовочные файлы;
- docs — документация;
- adr — архитектурные решения;
- sdd — проектная документация;
- CMakeLists.txt — файл сборки.
