# Калькулятор Жизни (вариант 14)

Учебный проект по дисциплине «Жизненный цикл и разработка ПО». Язык: C++17. GUI: Win32 API. Архитектура: MVC с активной моделью.

## Возможности

- кнопка «Ввести данные» открывает отдельное окно;
- ввод количества лет и часов работы за компьютером в день;
- проверка диапазонов: 0 < лет <= 120, 0 < часов <= 24;
- расчёт часов, суток, пробега курсора, кликов и нажатий клавиш;
- последние введённые данные восстанавливаются при следующем запуске и открытии окна.
- поддерживается ввод дробных значений как через точку, так и через запятую.

## Формулы и допущения

`calendarDays = years * 365.25`; `totalHours = calendarDays * hoursPerDay`; `totalDays = totalHours / 24`.

Для активного времени используется нормировка на 8-часовой рабочий день: `activeDays = calendarDays * hoursPerDay / 8`.
Статистические коэффициенты: 1.5 км движения курсора, 6000 кликов и 8000 нажатий клавиш на активный день. Это приближённая оценка: реальное значение зависит от профессии и стиля работы. Диапазоны и вариативность компьютерного ввода обсуждаются в [WhatPulse Research](https://whatpulse.org/research/how-much-people-really-type-and-click) и исследовании [PubMed](https://pubmed.ncbi.nlm.nih.gov/20392434/).

## Сборка в VS Code на Windows 10

1. Установить Visual Studio Build Tools с компонентом «Desktop development with C++» или MinGW-w64, CMake и расширение **C/C++**.
2. Открыть эту папку в VS Code.
3. Выполнить в терминале PowerShell:

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
.
build\LifeCalculator.exe
```

Для MSVC можно использовать генератор `Visual Studio 17 2022`, а запускать `build\Debug\LifeCalculator.exe`.

## MVC и активная модель

`LifeModel` хранит входные данные, выполняет расчёт и через Observer уведомляет `LifeView` о новом результате. `Controller` обрабатывает действие пользователя, передаёт данные модели и сохраняет их. `LifeView` отвечает только за окна и отображение. Таким образом, модель активна: после расчёта она сама вызывает `modelChanged`, а представление обновляет результат.

```plantuml
@startuml
actor Пользователь
class LifeView
class Controller
class LifeModel
Пользователь --> LifeView : ввод данных
LifeView --> Controller : команда
Controller --> LifeModel : calculate()
LifeModel --> LifeView : Observer: modelChanged()
Controller --> LifeModel : save()/load()
@enduml
```
